# Server Climate — климат серверной (Home Assistant)

Кастомная интеграция HA для управления климатом серверной techlan.su: **фрикулинг** (приточно-вытяжная
вентиляция по уличному воздуху) + два кондиционера (AUX / Oasis), с подтверждением факта по датчикам,
защитой от перегрева, обмерзания и неэффективного фрикулинга.

Вся логика — в интеграции. Прошивка ESPHome остаётся «тонкой»: датчики, реле, тахометр, входы кондиционеров.

## Возможности

| Что | Как работает |
|:--|:--|
| **Фрикулинг** | вентиляция включается, если на улице ниже порога (по умолчанию 10 °C) и в помещении ≥ уставки (22 °C) |
| **Жёсткая защита** | при падении ниже 15 °C вентиляция выключается принудительно |
| **Гистерезис** | выключение при `уставка − гистерезис` (1 °C) |
| **Кондиционеры** | при работающей вентиляции выключаются; при жаре выше порога (24 °C) — разрешаются; в обычном режиме живут по своим термостатам |
| **Контроль приточки** | через 20 с после включения проверяются обороты тахометра: не крутится — кондиционеры не блокируются + алерт |
| **Эффективность** | через 20 мин работы проверяется падение температуры на 0.5 °C; нет — «фрикулинг неэффективен» + алерт |
| **Мороз** | ниже −20 °C вентиляция работает циклами 5 мин / 10 мин |
| **Ручная пауза** | кнопки «не управлять N часов» / «снять паузу» |
| **Алерты** | окна на ПК через TechlanNotifier (перегрев, приточка не запустилась, фрикулинг неэффективен) |
| **Подтверждение** | состояние кондиционера берётся с входа УВ, команда повторяется раз в минуту до подтверждения |

## Установка

1. Скопировать `custom_components/server_climate` в `/config/custom_components/`.
2. Перезапустить Home Assistant.
3. Настройки → Устройства и службы → **Добавить интеграцию** → «Серверная — климат».
4. Выбрать сенсоры, выключатели вентиляции, кондиционеры, сцены и пороги.

Через HACS: добавить этот репозиторий как пользовательский (категория «Integration»).

## Сущности

- `sensor.servernaia_klimat_servernaia_status` / `…_prichina` — состояние и причина текстом
- `binary_sensor.…_problema` — проблема (с текстом в атрибуте)
- `switch.…_avtomatika` — автоматика вкл/выкл
- `button.…_pauza_ne_upravliat` / `…_sniat_pauzu`
- 11 `number.…` — уставка, гистерезис, нижний предел, порог улицы, порог кондиционеров, мороз ×3, эффективность ×2, длительность паузы

## Пороги по умолчанию

| Параметр | Значение |
|:--|:--|
| Уставка включения фрикулинга | 22 °C |
| Гистерезис выключения | 1 °C |
| Нижний предел (жёсткая защита) | 15 °C |
| Улица должна быть ниже | 10 °C |
| Разрешать кондиционеры выше | 24 °C |
| Мороз: циклы ниже / работать / пауза | −20 °C / 5 мин / 10 мин |
| Оценка эффективности | 20 мин, падение 0.5 °C |
| Ручная пауза | 2 ч |
| Тревога по температуре | 30 °C |
